# 雙語學習與操作指南 / Bilingual Learning Guide

## 讀法 / How to use
1. **中文：** 先讀 [完整架構](01-big-picture.md)，再開 [前 14 天每日手冊](../curriculum/first-14-days.md)。**English:** Read the [big picture](01-big-picture.md) then the [first-14-day manual](../curriculum/first-14-days.md).
2. **中文：** 每天先點官網「直接連結」，依指示找到標題；公司受限課程透過 Partner Academy 搜尋。**English:** Use the specific official URL and named section; search gated company content in Partner Academy.
3. **中文：** 將 SQL/Python 貼到指示位置，執行並比對結果。**English:** Run the code and compare with the expected output.
4. **中文：** 每天記錄一次成功、一次失敗，以及修復步驟。**English:** Record a success, a failure and a remedy.
5. **中文：** 每日完成後勾選 [Tracker](04-progress.md)。**English:** Tick the tracker only after passing acceptance criteria.

## 精確連結政策 / Link precision policy
- **Verified official public documentation**：提供直接 URL 和頁面標題。/ Exact official URL plus section title.
- **Employer-gated content**：標記 LOGIN REQUIRED；不虛構登入後影片連結。/ Login required; never fabricated internal lesson URLs.
- **Tool access unavailable**：提供標示為 Python/SQL 模擬的練習，但不聲稱完成工具實作。/ Clearly labelled fallbacks do not establish vendor tool proficiency.
- **Expected output**：示例資料的預期結果；可能受環境及版本影響。/ Expected for sample inputs, subject to runtime permissions/versions.
