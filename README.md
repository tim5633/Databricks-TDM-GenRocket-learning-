## Mission / 目標
Build a working **Financial Test Data & AI Engineering Platform** while preparing for **Databricks Data Engineer Associate, Data Engineer Professional, Generative AI Engineer Associate and Context Engineer Associate**. Prioritize **GenRocket** hands-on and enterprise **TDM strategy**, study **MOSTLY AI** with a working SDK example, and compare **Delphix, Informatica TDM and Broadcom TDM** for tool selection.

**Baseline:** already comfortable with Python, SQL, ETL and data-quality analytics. Not starting those skills from scratch; new to TDM. **Study budget:** up to **7 active study hours/day**, breaks excluded; lighter exam/recovery days permitted. The four exam dates are targets, *not booked exams or guaranteed outcomes*.
